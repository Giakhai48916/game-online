# THE BACKROOMS 3D (Bản Sans 3D Sculpted Chuẩn Mẫu)

## Nâng cấp trong bản này
- **Đầu sọ Sans điêu khắc 1 khối liền mạch:** Bỏ hẳn 2 cục má phồng cũ, điêu khắc gò má nhẹ tự nhiên, hốc mắt lõm 3D thật, mắt to rõ đúng tỉ lệ với mặt, lỗ mũi hình tim ngược, miệng cười rộng với 8 răng sắc nét và màu xương ngà ấm không cháy sáng.
- **Áo hoodie & tay áo liền mạch:** Áo khoác xanh mở phanh 1 mảnh liền mạch, dây rút màu đen, viền khóa kéo xám, mũ hoodie xám sáng rủ sau lưng, tay áo đút túi uốn cong mượt có sọc trắng chạy dọc mặt ngoài.
- **Quần đùi & dép bông hồng:** Quần đùi đen có sọc trắng đôi hai bên, ống chân xương ngắn chuẩn tỉ lệ chibi, dép lê bông hồng hở gót có đế hồng.
- **Ánh sáng Studio khung xem trước:** Cân chỉnh độ tương phản để không bị lóa trắng, giữ rõ khối 3D.

## Cách cập nhật lên GitHub
Giải nén file `.zip` và tải đè các file (`model.js`, `game.js`, cùng các file còn lại) lên nhánh `main` của GitHub Repository rồi nhấn `Ctrl + F5`.
